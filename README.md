# Muhammad Rehan | Portfolio

Personal developer portfolio built with vanilla HTML, CSS and JavaScript.

## Highlights

- Responsive desktop and mobile layout
- Mobile navigation menu
- Scroll reveal animations
- Active navigation based on the current section
- SEO and social sharing metadata
- Accessible skip link and reduced-motion support
- Project showcase and contact section
- No framework or build step required

## Tech Stack

HTML5 · CSS3 · JavaScript · GitHub

## Run locally

Open `index.html` in a browser. No installation or build process is required.
